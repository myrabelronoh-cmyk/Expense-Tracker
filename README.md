# My Expense Tracker

A browser-based expense and income tracker using Kenyan shillings (KES). Track your balance, review spending, set category budgets, and manage transactions from a single dashboard.

## Features

- Add, edit, and delete income and expense transactions
- View income, expenses, balance, and savings rate
- Review spending in the monthly chart and filter by category
- Monitor category budget progress
- Save transactions and theme preference in browser local storage
- Toggle dark mode
- Format amounts as Kenyan shillings (KES)

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server. The app uses plain HTML, CSS, and JavaScript; no build step is required.

## Project files

- `index.html` — dashboard structure
- `styles.css` — layout, responsive styles, and dark theme
- `script.js` — transaction logic, rendering, and local storage
